# Casos de Uso

## UC01 - Realizar Cadastro

### Ator Principal
Participante

### Fluxo Principal

1. Usuário acessa o sistema.
2. Seleciona cadastro.
3. Informa os dados solicitados.
4. Sistema valida os dados.
5. Sistema registra o participante.

### Fluxo Alternativo

4a. Dados inválidos.

4a1. Sistema exibe mensagem de erro.

4a2. Usuário corrige os dados.

## UC02 - Consultar Atividades

### Ator Principal
Participante

### Fluxo Principal

1. Usuário acessa a lista de atividades.
2. Sistema exibe as atividades disponíveis.
3. Usuário consulta os detalhes.

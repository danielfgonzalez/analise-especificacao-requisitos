# Histórias de Usuário

## HU01 - Cadastro de Participante

Como participante,

Quero realizar meu cadastro no sistema,

Para participar das atividades disponíveis.

### Critérios de Aceitação
- Informar nome completo.
- Informar e-mail válido.
- Sistema confirmar cadastro.

---

## HU02 - Consultar Atividades

Como participante,

Quero visualizar as atividades disponíveis,

Para escolher aquelas que desejo participar.

### Critérios de Aceitação
- Exibir lista de atividades.
- Mostrar data e horário.
- Permitir consulta das informações.

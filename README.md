# Sistema de Gestão de Eventos

## Descrição

Este repositório contém a análise e especificação de requisitos de um Sistema de Gestão de Eventos, desenvolvida como atividade prática da disciplina de Engenharia de Requisitos.

O objetivo do sistema é oferecer suporte ao gerenciamento de eventos, workshops e participantes, permitindo o controle de inscrições, vagas, pagamentos, certificados e demais atividades relacionadas à organização de eventos.

Durante a atividade foi realizada a análise de um documento de elicitação de requisitos com o apoio de Inteligência Artificial Generativa para identificar:

- Requisitos Funcionais;
- Regras de Negócio;
- Requisitos Não Funcionais;
- Dúvidas, Lacunas e Ambiguidades;
- Artefatos de especificação adequados para representação da solução.

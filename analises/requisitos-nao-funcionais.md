# Requisitos Não Funcionais (RNF) — Sistema de Gestão de Eventos

Os requisitos não funcionais definem características de qualidade e restrições do sistema.

| ID | Requisito Não Funcional | Categoria |
|----|-------------------------|-----------|
| RNF01 | Garantir conformidade com a LGPD para tratamento de dados pessoais. | Segurança e Privacidade |
| RNF02 | Restringir o acesso às informações de acordo com o perfil do usuário. | Segurança |
| RNF03 | Utilizar meios seguros para processamento de pagamentos. | Segurança |
| RNF04 | Atualizar informações de vagas e inscrições em tempo real ou quase real. | Desempenho |
| RNF05 | Garantir consistência das vagas em acessos simultâneos. | Confiabilidade |
| RNF06 | Manter disponibilidade adequada durante períodos de alta demanda. | Disponibilidade |
| RNF07 | Atender diretrizes de acessibilidade digital. | Acessibilidade |
| RNF08 | Registrar auditoria de operações críticas do sistema. | Auditabilidade |
| RNF09 | Apresentar tempo de resposta adequado para consultas e inscrições. | Desempenho |
| RNF10 | Funcionar corretamente em dispositivos móveis e computadores. | Usabilidade |
| RNF11 | Suportar crescimento da quantidade de eventos e participantes. | Escalabilidade |

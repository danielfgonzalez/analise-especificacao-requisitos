# Requisitos Funcionais (RF) — Sistema de Gestão de Eventos

Os requisitos funcionais descrevem as funcionalidades que o sistema deve oferecer aos usuários.

| ID | Requisito Funcional |
|----|---------------------|
| RF01 | Permitir que participantes visualizem todos os eventos disponíveis. |
| RF02 | Permitir a inscrição em eventos e workshops. |
| RF03 | Gerar e disponibilizar comprovante de inscrição automaticamente. |
| RF04 | Permitir cancelamento de inscrição, quando autorizado pelo organizador. |
| RF05 | Permitir emissão de certificados após o evento. |
| RF06 | Permitir inscrição em múltiplos workshops sem conflito de horário. |
| RF07 | Controlar automaticamente a quantidade de vagas disponíveis. |
| RF08 | Gerenciar lista de espera para eventos lotados. |
| RF09 | Permitir que organizadores configurem políticas de cancelamento. |
| RF10 | Exibir aos organizadores a quantidade de inscritos em tempo real. |
| RF11 | Impedir inscrições em atividades com horários sobrepostos. |
| RF12 | Diferenciar eventos gratuitos e pagos. |
| RF13 | Registrar e confirmar pagamentos de inscrições. |
| RF14 | Liberar inscrições pagas somente após validação financeira. |
| RF15 | Permitir processamento de reembolsos quando aplicável. |
| RF16 | Permitir que palestrantes consultem a lista de inscritos de suas atividades. |
| RF17 | Permitir criação e gerenciamento de eventos pelos organizadores. |
| RF18 | Permitir gerenciamento de participantes inscritos. |
| RF19 | Enviar notificações relacionadas à inscrição e participação em eventos. |
